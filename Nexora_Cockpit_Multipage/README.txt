NEXORA COCKPIT — TEMPLATE HTML

Como abrir
1. Extraia o ZIP.
2. Mantenha a pasta assets junto dos arquivos HTML.
3. Abra index.html em qualquer navegador moderno.

O template funciona sem instalação. Todas as páginas usam um único CSS global e um
único JavaScript global, localizados em assets/css/global.css e assets/js/app.js.

Arquivos HTML
- index.html — cockpit inicial
- projects.html — gestão de projetos
- chat.html — chat, execução e fontes
- credits.html — saldo, consumo e histórico
- plans.html — planos e cobrança
- profile.html — perfil, workspace, aparência e segurança
- login.html — acesso à plataforma

Observação: ações de IA, pagamento e persistência usam dados simulados para demonstrar
o layout e as interações. Integre seu backend nos handlers JavaScript quando necessário.
